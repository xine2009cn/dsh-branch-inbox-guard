# dsh-branch-inbox-guard
A DeepSeek Harness (DSH) plugin that removes the queued prompts a fork child inherits from its parent, so a new branch runs the prompt you type instead of the parent's next one. Host-side bundle, no core patching.

DSH 插件：清除分支会话从父会话继承来的排队提问，让新分支执行你输入的问题，而不是父会话的下一句。纯宿主插件，不改核心包。
